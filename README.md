Whisper Audio Transcription & Sentiment Analysis

This project is a simple AI-powered audio transcription and sentiment analysis web app built using OpenAI Whisper, Streamlit, and TextBlob.

Features

- Upload audio files ("mp3", "wav", "m4a", "ogg")
- Convert speech to text using Whisper
- Detect sentiment from the transcript
- Shows:
  - Positive 🙂
  - Negative 😠
  - Neutral 😐 sentiment

Technologies Used

- Python
- Streamlit
- OpenAI Whisper
- FFmpeg
- TextBlob

Installation

pip install streamlit openai-whisper textblob

Install FFmpeg and make sure it is added to system PATH.

Run the App

streamlit run app.py

Project Output

- Audio transcription
- Sentiment score
- Positive/Negative/Neutral analysis
